# Fish model and reference sources

## Shipped GLB models

The npm package ships only the six GLBs compiled from `src/assets/current-preview/`: black carp native-v7, grass carp v13, and silver/bighead/common/ordinary-crucian native-v7. See ASSET_MANIFEST.json for exact hashes and THIRD_PARTY_NOTICES.md for retained attribution. All use independently authored Blender geometry and native nine-bone animation. They remain unaccepted approximations, not scans or claims of photographic realism.

Editable matching Blender sources are retained under models/current-preview/ in the source repository, not the npm tarball. Earlier assets and reference photographs remain in recoverable local authoring archives and are not included in this source release or npm tarball. The earlier morphometric-proportions-v6 and anatomy-separated-pbr-v5 assets are historical and are not loaded by the current package. Current ordinary-crucian is Carassius auratus; no finished third-party mesh or rig is bundled. Common-carp local head detail uses USFWS public-domain reference; current ordinary-crucian uses authored skin, with previous photo-reference attribution preserved. Keep the conservative retained derivative-material permissions listed below when distributing these GLBs.

## Modeling references

The subsequent reference investigation and its reference catalog are retained in the local authoring archive, outside this source release and npm tarball. New authoring photographs include USGS's public-domain black-carp ventral head, Ryan Hagerty/USFWS's public-domain grass-carp head, Vladislav Isaev's CC BY bighead-carp photographs (iNaturalist photo IDs 624399778 and 624399724), and naturalist132890's CC BY ordinary-crucian photographs (IDs 406505226 and 406088127). These authoring references are retained in the local modeling archive, outside this source release and npm tarball; ordinary-crucian photo 406505226 supplied surface detail in the retained historical assets; the current native-v7 candidate uses authored geometry, native scale bakes and procedural pigment, with these photographs used for qualitative shape study. Photo 406088127 is another head-right lateral view, despite its legacy filename ending in `left`, and is not proof of the opposite flank. Uwe Ohse's copyright-reserved frontal carp photograph is an external study reference and is not bundled with the package. None of these fish has a verified same-individual whole-fish six-view photo set yet.

- [RetopoFlow](https://github.com/CGCookie/retopoflow) informed reference-supported quad topology; its addon and code are not included. [glTF-Blender-IO](https://github.com/KhronosGroup/glTF-Blender-IO) is Blender's existing bundled exporter.
- [FishSim](https://github.com/nerk987/FishSim) provides a mature Blender workflow with body, tail, and paired-fin controls. It informed the separation of anatomical parts; its code, rigs, and fish models are not bundled.
- [Three.js GLTFLoader example](https://github.com/mrdoob/three.js/blob/dev/examples/webgl_loader_gltf_compressed.html) demonstrates `RoomEnvironment` and PMREM lighting for glTF materials. This package uses the installed Three.js addon without downloading an HDR or adding a dependency.
- [camera-controls fitToBox](https://github.com/yomotsu/camera-controls/blob/master/src/CameraControls.ts) informed fitting the fish's bounding box in camera space. The package retains its existing Three.js `OrbitControls`.
- [paper-aquarium](https://github.com/MrMoT9I/paper-aquarium) documents mapping photographs onto complete fish models. Its source code and purchased model pack are not included here.
- [rembg](https://github.com/danielgatis/rembg) with the explicitly selected [U²-Net model](https://github.com/xuebinqin/U-2-Net) is used only by the local asset-authoring script to segment the fish from each photo.
- [Aquascape fish anatomy](https://github.com/joebarbere/aquascape/tree/main/libs/domain/fish-anatomy) informed the use of longitudinal body sections; this package's photo-specific mesh construction is independently authored because no redistributable six-species model set was available.
- [Google WebGL Aquarium](https://github.com/WebGLSamples/WebGLSamples.github.io/blob/master/aquarium/aquarium.html) informed the body-position-weighted tail-sway animation; its fish meshes are not included.

- [Infinigen fishbody](https://github.com/princeton-vl/infinigen/blob/nature-stable/infinigen/assets/materials/fishbody.py) informed keeping surface color and roughness as separate material inputs; no source or asset is bundled. [Retinex](https://github.com/muggledy/retinex/blob/master/code/retinex.py) informed bounded photo-detail illumination normalization.
