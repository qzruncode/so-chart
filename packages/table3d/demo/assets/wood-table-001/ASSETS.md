# Wood Table 001 texture maps

The source bundle includes the 1K diffuse, OpenGL normal, and roughness maps from [Poly Haven: Wood Table 001](https://polyhaven.com/a/wood_table_001). The demo uses all three maps; the roughness scalar is kept high so the low-valued roughness map still leaves visible, controlled variation across the tabletop.

- Photographer: Dimitrios Savva; processing: Rico Cilliers.
- License: CC0 1.0 Universal, as identified on the asset page.
- Download source: `https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/wood_table_001/`

The maps are stored locally; the preview bundles the selected diffuse, normal, and roughness maps and makes no remote texture requests at runtime.
