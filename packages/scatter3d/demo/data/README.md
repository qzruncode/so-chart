# Iris 示例数据

`iris-data.csv` 来源于 Plotly 的公开数据仓库：

- 来源：[plotly/datasets/iris-data.csv](https://github.com/plotly/datasets/blob/master/iris-data.csv)
- 许可：[MIT License](https://github.com/plotly/datasets/blob/master/LICENSE)

Demo 将 `sepal length`、`sepal width`、`petal length` 映射到 X、Y、Z，将 `petal width` 放入点对象的 `value`，并按 `class` 拆分为三个数据系列。
